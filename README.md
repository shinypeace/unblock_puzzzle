# Сдвиг

Вертикальная браузерная unblock-головоломка с установкой как PWA.

[Играть в браузере](https://shinypeace.github.io/unblock_puzzzle/)

- 420 уровней, 7 глав, точный оптимум от 2 до 29 ходов.
- 240 отдельных задач для ежедневного набора, дзена и спринта.
- Ежедневная серия, монеты, 18 достижений, подсказки и расходуемые отмены.
- Семь самостоятельных растровых тем: игрушки, автопарк, подводный мир, кондитерская, неон, деревянная мастерская и сад камней. У каждой свои блоки, поле, кнопки, панели, вкладки, сундук и вертикальный фон.
- Закрытые темы раскрываются только после покупки.
- Мышь, касания и клавиатура. На ПК сохраняется компактное окно шириной до 460 px.
- Автосохранение и офлайн после первого открытия. Все игровые спрайты и шрифты предварительно загружаются и декодируются.
- VK Bridge: сохранение прогресса в аккаунте, баннер, межэкранная реклама и добровольное видео за буст. В обычном браузере Bridge не запрашивается.

## Запуск и сборка

Node.js 20.17+ или 22 LTS.

```sh
npm ci
npm run dev
npm run build
npm run preview
```

Публикуется содержимое `dist/` на HTTPS-хостинге. Относительные пути поддерживают подпапки, в том числе GitHub Pages. PWA устанавливается через меню браузера, ориентация — portrait. При запуске одного приложения VK с одного аккаунта прогресс синхронизируется между устройствами. Обычная ссылка GitHub Pages и отдельная PWA работают с локальным сохранением: входа в аккаунт VK вне платформы нет.

GitHub Actions автоматически проверяет `main`, собирает игру и публикует проверенный `dist/` через GitHub Pages. Исходный `index.html` из корня репозитория запускать на Pages нельзя: он предназначен для Vite. Для нового подключения Pages выберите **Settings → Pages → Source → GitHub Actions**.

## Музыка

Загрузите **music.mp3 в папку public/**: итоговый путь — `public/music.mp3`. Следующая сборка GitHub Actions автоматически добавит музыку в игру и офлайн-кэш. Она зацикленно воспроизводится после первого касания. Приоритет: public/music.mp3, music.mp3, public/music.png, music.png. Старое имя music.png сохранено для совместимости, но внутри него тоже должны быть аудиоданные. Без файла игра работает без фоновой музыки. Звук выключается в настройках и при рекламе или скрытии вкладки.

## Проверки

```sh
npm test
npx playwright install --with-deps chromium firefox webkit
npm run build
npm run test:e2e
```

Модульные проверки независимо решают все 660 задач и подтверждают оптимальность, уникальность, допустимость ходов, экономику и выдачу рекламных наград. Браузерные проверки охватывают перетаскивание и восстановление после потери захвата, касания, клавиатуру, сохранение, покупки, все темы, ежедневные задачи, спринт, офлайн и VK со стендом Bridge. Отдельно проверяются точные координаты 36 ячеек, границы спрайтов и безопасные внутренние отступы панелей на 320×568 с баннером. Реальные рекламные показы проверяются отдельно внутри приложения VK с включённой монетизацией: [подключение VK](docs/VK.md).

## Контент

```sh
npm run generate
npm run assets
```

Генератор перебирает полную связную компоненту допустимых расстановок и запускает BFS от всех решённых состояний. Сложность — точное расстояние до выхода. Подробности и исследование жанра: [игровая система](docs/DESIGN.md).

Растровая графика создана встроенным ImageGen. Оригиналы: `art/source/`, сохранённые промпты: `art/prompts/`. Команда `assets` извлекает спрайты по прозрачности, создаёт WebP-атласы и мобильные иконки; ничего не рисует кодом. Готовые игровые файлы: `public/art/`, координаты спрайтов: `public/art/manifest.json`.

| Файл                   | Назначение                                                           |
| ---------------------- | -------------------------------------------------------------------- |
| `src/engine.js`        | Правила, столкновения, BFS-решатель                                  |
| `src/store.js`         | Сохранения, экономика, ежедневные задачи                             |
| `src/cloud.js`         | Синхронизация VK, объединение результатов и очередь офлайн-изменений |
| `src/main.js`          | Экраны, управление, жизненный цикл партии                            |
| `src/vk.js`            | Инициализация VK, реклама и события приложения                       |
| `src/raster.css`       | Вертикальная компоновка и размещение растровых ассетов               |
| `src/solver.worker.js` | Подсказки вне основного потока                                       |
| `src/data/levels.json` | Каталог уровней и оптимальные решения                                |
| `vite.config.js`       | Сборка и версионированный офлайн-кэш                                 |

Service Worker применяет обновления после закрытия старых вкладок. Ежедневный набор меняется в местную полночь. Обычное переключение вкладки не останавливает спринт; время рекламы и скрытия приложения через события VK исключается из таймера. Расчёт экономики выполняется на клиенте, защиты от ручного редактирования сохранений нет.
