# Сдвиг

Вертикальная браузерная unblock-головоломка с установкой как PWA.

- 420 уровней, 7 глав, точный оптимум от 2 до 29 ходов.
- 240 отдельных задач для ежедневного набора, дзена и спринта.
- Ежедневная серия, монеты, 8 достижений, 3 вида бустов.
- Пять самостоятельных растровых тем: игрушки, автопарк, подводный мир, кондитерская и неон. У каждой свои блоки, поле, кнопки, панели, вкладки, сундук и вертикальный фон.
- Закрытые темы раскрываются только после покупки.
- Мышь, касания и клавиатура. На ПК сохраняется компактное окно шириной до 460 px.
- Автосохранение и офлайн после первого открытия. Шрифты и графика локальные.
- VK Bridge: баннер, межэкранная реклама и добровольное видео за буст. В обычном браузере реклама не запрашивается.

## Запуск и сборка

Node.js 20.17+ или 22 LTS.

```sh
npm ci
npm run dev
npm run build
npm run preview
```

Публикуется содержимое `dist/` на HTTPS-хостинге. Относительные пути поддерживают подпапки, в том числе GitHub Pages. PWA устанавливается через меню браузера, ориентация — portrait. Прогресс локальный и привязан к адресу игры; облачной синхронизации и переноса между устройствами нет.

## Проверки

```sh
npm test
npx playwright install --with-deps chromium firefox webkit
npm run build
npm run test:e2e
```

Модульные проверки независимо решают все 660 задач и подтверждают оптимальность, уникальность, допустимость ходов, экономику и выдачу рекламных наград. Браузерные проверки охватывают перетаскивание, касания, клавиатуру, сохранение, покупки, все темы, ежедневные задачи, спринт, офлайн и VK со стендом Bridge. Реальные рекламные показы проверяются отдельно внутри приложения VK с включённой монетизацией: [подключение VK](docs/VK.md).

## Контент

```sh
npm run generate
npm run assets
```

Генератор перебирает полную связную компоненту допустимых расстановок и запускает BFS от всех решённых состояний. Сложность — точное расстояние до выхода. Подробности и исследование жанра: [игровая система](docs/DESIGN.md).

Растровая графика создана встроенным ImageGen. Оригиналы: `art/source/`, сохранённые промпты: `art/prompts/`. Команда `assets` извлекает спрайты по прозрачности, создаёт WebP-атласы и мобильные иконки; ничего не рисует кодом. Готовые игровые файлы: `public/art/`, координаты спрайтов: `public/art/manifest.json`.

| Файл | Назначение |
| --- | --- |
| `src/engine.js` | Правила, столкновения, BFS-решатель |
| `src/store.js` | Сохранения, экономика, ежедневные задачи |
| `src/main.js` | Экраны, управление, жизненный цикл партии |
| `src/vk.js` | Инициализация VK, реклама и события приложения |
| `src/raster.css` | Вертикальная компоновка и размещение растровых ассетов |
| `src/solver.worker.js` | Подсказки вне основного потока |
| `src/data/levels.json` | Каталог уровней и оптимальные решения |
| `vite.config.js` | Сборка и версионированный офлайн-кэш |

Service Worker применяет обновления после закрытия старых вкладок. Ежедневный набор меняется в местную полночь. Обычное переключение вкладки не останавливает спринт; время рекламы и скрытия приложения через события VK исключается из таймера. Экономика локальная, защиты от редактирования сохранений нет.
