# VK Mini Apps

Интеграция адаптирована из проекта Void Storm и использует локально собранный пакет @vkontakte/vk-bridge 3.0.2. Игра определяет запуск по vk_app_id или предоставленному window.vkBridge. В обычном браузере и установленной PWA Bridge не загружается.

## Публикация

1. Выполнить npm ci и npm run build.
2. Разместить содержимое dist на HTTPS-хостинге.
3. Указать этот HTTPS-адрес в настройках своего приложения VK Mini Apps для нужных платформ.
4. Включить монетизацию приложения и доступные рекламные форматы в кабинете VK.
5. Открывать игру из VK с подписанными параметрами запуска; проверить показ на реальном устройстве.

ID приложения не зашит в исходники. Публикация игры на GitHub сама по себе не создаёт приложение VK и не включает монетизацию.

## Поведение

- После VKWebAppInit баннер запрашивается через VKWebAppShowBannerAd с bottom, resize и can_close:false. Для старых клиентов при коде 3/4 есть повтор с базовыми параметрами.
- При overlay резервируется фактическая banner_height, до 150 px. При resize повторного отступа нет.
- События обновления и закрытия баннера меняют отступ. Ошибка не блокирует игру; следующая попытка не чаще 60 секунд, при закрытии — от 15 секунд.
- Межэкранная реклама возможна по кнопке «Дальше» после трёх завершённых задач продолжительностью от 15 секунд. Интервал между полноэкранными показами — минимум 180 секунд. Во время активной задачи или спринта автоматических показов нет.
- На поддерживающих клиентах используется VKWebAppShowInterstitialAd, при неподдерживаемом методе — VKWebAppShowNativeAds с ad_format:interstitial.
- Кнопка «Видео · +1» в магазине помощников и подсказках запускает VKWebAppShowNativeAds с ad_format:reward.
- Ровно один выбранный буст выдаётся только при result:true. Отказ, result:false, отсутствие результата, ошибка и таймаут награды не дают.
- Одновременные запросы блокируются. На время полноэкранной рекламы отключаются ввод и звук. Таймер спринта компенсирует время рекламы; события VKWebAppViewHide / ViewRestore также приостанавливают игру.
- Ошибка инициализации оставляет обычную игру рабочей.

## Проверка

Автотесты подменяют Bridge: проверяют резерв под баннер, старые клиенты, успешное/отменённое видео, однократность выдачи, восстановление таймера и частоту межэкранной рекламы. Реальный рекламный инвентарь и доступность конкретных методов зависят от настроек приложения и клиента VK; их нельзя подтвердить localhost-тестом.

Официальные типы запросов: [VK Bridge](https://github.com/VKCOM/vk-bridge/blob/master/packages/core/src/types/data.ts), [методы Bridge](https://github.com/VKCOM/vk-bridge/blob/master/packages/core/src/types/bridge.ts).
